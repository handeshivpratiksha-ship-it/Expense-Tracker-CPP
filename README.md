# Expense Tracker CPP

A simple **Expense Tracker application built using C++** that allows users to add, view, search, delete, and calculate total expenses.

## Features

- Add a new expense
- View all expenses
- Calculate total expenses
- Search expenses by category
- Delete an expense
- Save expenses to a file
- Load previously saved expenses automatically

## Technologies Used

- C++
- Structures
- Vector
- File Handling (`fstream`)
- Functions

## Data Stored

Each expense contains:

- **Category**
- **Amount**
- **Date**

## How to Run

1. Clone or download this repository.
2. Open the project in VS Code or any C++ IDE.
3. Compile the C++ program.
4. Run the program.
5. Use the menu to manage your expenses.

## Menu

```text
1. Add Expense
2. View Expenses
3. Total Expense
4. Search Expense
5. Delete Expense
6. Exit
```
